# לוז מכבי 3

דף אינטרנט + מנוי יומן להורים ולשחקנים. אין צורך בקלוד או בכל מנוי.
המשחקים נמשכים אוטומטית מדף הנבחרת באתר איגוד הכדורעף, וחופשות משרד החינוך נשמרות בקובץ נתונים.

## העלאה לאוויר (פעם אחת, כ-10 דקות)

1. פתחו חשבון חינם ב-github.com ויצרו ריפו חדש (ציבורי; ב-Pages חינמי הדף חייב להיות ציבורי) בשם למשל `maccabi3`.
2. העלו אליו את כל תוכן התיקייה הזו (Add file → Upload files, גררו הכול כולל תיקיית `.github`).
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, תיקייה `/docs` → Save.
4. לשונית Actions → `update-schedule` → Run workflow. **זו הבדיקה החשובה:** ודאו בלוג שכתוב `נסרקו 16 משחקים`.
5. הקישור לדף יופיע ב-Settings → Pages (בדרך כלל `https://<שם-משתמש>.github.io/maccabi3/`). שלחו אותו פעם אחת בקבוצת ההורים.

## מה מתעדכן לבד

- כל 3 שעות: משיכת הלוז מההתאחדות, בניית הדף ופידי היומן.
- בכל שינוי בקבצי `data/` או `config.json`: בנייה מחדש מיד.
- אם הסריקה נכשלת: הדף ממשיך להציג את הנתונים האחרונים עם הודעת אזהרה להורים, ואחרי 36 שעות GitHub שולח לכם מייל על כשל.

## תיקונים ידניים (בלי קוד)

כל הקבצים נערכים ישירות באתר GitHub (כפתור העיפרון).

| מה | איפה |
|---|---|
| לסמן משחק כנדחה/בוטל לפני שההתאחדות עדכנה | `data/overrides.json`: `{"da1ydX": {"status": "postponed", "note": "מועד חדש יפורסם"}}` (המזהה הוא ה-`id` מתוך `data/games_scraped.json`) |
| להוסיף כתובת לאולם (לניווט מדויק) | `data/venues.json`, שדה `address`, ו-`"verified": true` |
| משחק ידידות או משחק שלא מופיע בהתאחדות | `data/games_manual.json` (`date`, `time`, `opponent`, `venue`) |
| שינוי זמן כינוס / אורך משחק | `config.json`: `default_gather_min`, `default_duration_min` |

שגיאה בקובץ ידני (למשל תאריך לא תקין) עוצרת את העדכון, האתר הקודם נשאר, ותקבלו מייל מ-GitHub עם הסבר בעברית.

## נקודות חשובות

- **עונה חדשה:** בקישור ב-`config.json` (`cYear=2027`) יש לעדכן את השנה, ולעדכן `data/holidays.json` ללוח החופשות של השנה החדשה.
- **לוח החופשות** נאסף ממקורות פומביים ולא מחוזר המנכ"ל הרשמי (האתר שלו חוסם קריאה אוטומטית). בדקו את הפריטים המסומנים `disputed` ב-`data/holidays.json`.
- **בדיקות:** `python tests/test_pipeline.py` (דורש `pip install -r requirements.txt icalendar`).

## מבנה

```
docs/            האתר (index.html, data.json, maccabi3.ics, maccabi3-with-holidays.ics)
data/            נתוני מקור (חופשות, אולמות, תיקונים ידניים, משחקים שנסרקו)
scripts/         scrape.py (משיכה מההתאחדות), build.py (בנייה)
state/           מצב פנימי (מספרי גרסה לאירועי יומן, סטטוס סריקה)
.github/         ההרצה האוטומטית
```
